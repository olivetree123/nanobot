# 问题3：如果设置了 unifiedSession = True，会有什么效果
设置 `unifiedSession = True` 会让所有渠道的消息共享同一个会话，实现跨平台的连续对话。

## 核心效果

当启用 `unifiedSession` 时，nanobot 会将所有来自不同渠道的消息路由到同一个共享会话中，而不是为每个 `channel:chat_id` 组合创建独立会话 。

## 具体行为变化

### 会话键映射
- **默认模式** (`unifiedSession: false`): 会话键为 `channel:chat_id`（如 `telegram:123456`）
- **统一模式** (`unifiedSession: true`): 会话键统一为 `unified:default`

### 实现机制
在 `AgentLoop._dispatch()` 方法中，如果启用了统一会话且消息没有 `session_key_override`，系统会重写会话键：

```python
def _effective_session_key(self, msg: InboundMessage) -> str:
    if self._unified_session and not msg.session_key_override:
        return UNIFIED_SESSION_KEY  # "unified:default"
    return msg.session_key
```

### 命令行为
- `/new` 命令会清除共享会话，影响所有渠道
- `/stop` 命令可以取消来自任何渠道的任务

## 配置示例

```json
{
  "agents": {
    "defaults": {
      "unifiedSession": true
    }
  }
}
```

## 注意事项

1. **保留特殊会话**：如果消息已有 `session_key_override`（如 Telegram 线程），不会被覆盖
2. **单用户设计**：此功能专为单用户多设备场景设计，默认关闭以确保现有用户行为不变
3. **内存整合**：所有渠道的消息历史和上下文会合并到同一个会话文件中

## Notes

- 统一会话功能不影响会话压缩（consolidation）逻辑
- 配置文件中使用驼峰命名 `unifiedSession`，但代码内部使用下划线 `unified_session`
- 适用于希望在不同设备/平台间无缝切换对话的个人用户场景

# AutoCompact 概述

AutoCompact 是 nanobot 的主动会话压缩机制，用于在用户空闲时自动压缩旧消息以减少令牌成本和延迟。

## 核心功能

当用户空闲时间超过配置的阈值时，AutoCompact 会主动压缩会话的旧部分为摘要，同时保留最近的法律后缀消息。

## 工作原理

### 1. 空闲检测
在每个空闲时刻（约1秒），检查所有会话是否过期。

### 2. 后台压缩
过期会话通过 LLM 总结旧的活动前缀，保留最近的法律后缀（当前为8条消息）。

### 3. 摘要注入
当用户返回时，摘要作为运行时上下文注入（一次性，不持久化），与保留的最近后缀一起提供。

## 配置

通过 `idleCompactAfterMinutes` 配置空闲阈值（默认为0，禁用）：

```json
{
  "agents": {
    "defaults": {
      "idleCompactAfterMinutes": 15
    }
  }
}
```

## 核心方法

### check_expired
调度过期会话的归档，跳过有活跃代理任务的会话。

### _archive
实际执行归档操作，调用 Consolidator 总结消息并更新会话状态。

### prepare_session
在消息处理前准备会话，恢复摘要并清理元数据。

## 集成方式

AutoCompact 在 AgentLoop 初始化时创建，并在主循环的超时路径中调用。

## 关键特性

- **重启安全**：摘要同时保存在内存和会话元数据中，进程重启后仍可恢复 
- **任务感知**：跳过有活跃任务的会话，避免中断正在进行的操作
- **边界对齐**：保留最近8条消息以维持对话连续性

## Notes

- AutoCompact 与 Consolidator 不同：AutoCompact 是主动触发（基于空闲时间），Consolidator 是被动触发（基于令牌限制）
- 推荐设置为15分钟，接近典型的 LLM KV 缓存过期窗口
- 测试覆盖了各种场景，包括多会话、活跃任务、进程重启等
